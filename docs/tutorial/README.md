# Учебник: персональный сайт с нуля

Этот учебник объясняет, как устроен сайт из этого репозитория, и учит собрать такой же самому.
Он идёт от общей картины к деталям: сначала что строим и почему именно так, потом каждая часть — контент,
шаблоны, стили, админка, сборка, сервер, выкладка.

Каждая глава устроена одинаково:

1. **Зачем** — какую задачу решает эта часть сайта.
2. **Как сделано здесь** — настоящий код из репозитория с путём к файлу.
3. **Разбор** — что делает каждая строка и каждый параметр.
4. **А если иначе** — что будет, если поменять параметр, убрать строку или выбрать другой подход.
   Пометка **«Проверено»** значит, что так и сделали на Hugo 0.169 и посмотрели на результат.
   Остальное взято из документации.
5. **Где ещё пригодится** — другие применения той же функции или приёма.
6. **Упражнения** — небольшие задания, чтобы закрепить главу. Делайте их в отдельной ветке.

## Карта репозитория

```
.
├── hugo.yaml                 настройки Hugo                              → глава 2
├── Makefile                  короткие команды: make dev, make build       → глава 2
├── content/                  тексты страниц (Markdown)                   → глава 3
│   ├── projects/<адрес>/index.md   проект + его картинки рядом
│   └── posts/<адрес>/index.md      запись + её картинки рядом
├── data/site.yaml            имя, «обо мне», ссылки, цвет акцента        → глава 3
├── i18n/ru.yaml              склонение «1 запись / 2 записи / 5 записей» → глава 4
├── layouts/                  HTML-шаблоны                                 → главы 4, 5, 7
│   ├── baseof.html           общий каркас всех страниц
│   ├── home.html, page.html, section.html, 404.html
│   ├── posts/, projects/     шаблоны конкретных разделов
│   ├── _partials/            переиспользуемые куски
│   └── _markup/              render-хуки: картинки и формулы в Markdown
├── assets/                   то, что Hugo обрабатывает при сборке
│   ├── css/main.css, syntax.css                                           → глава 6
│   └── uploads/              общие картинки (аватар и т. п.)
├── static/                   копируется на сайт как есть
│   ├── admin/                админка: index.html + config.yml             → глава 8
│   └── katex/                стили и шрифты для формул                    → глава 5
├── .github/workflows/deploy.yml   сборка и выкладка                       → глава 9
└── deploy/                   скрипты сервера                              → главы 10, 11
    ├── setup-server.sh, Caddyfile
    └── publish.sh, rollback.sh
```

## Что нужно знать заранее

- Основы HTML (теги, атрибуты) и CSS (селекторы, свойства). Учебник объясняет приёмы, а не азы.
- Командная строка: перейти в папку, запустить команду.
- Git: `clone`, `commit`, `push`, ветки.

Программировать на Go не нужно: шаблоны Hugo используют только язык шаблонов Go, а он объясняется в главе 4.

## Как поддерживать учебник

Учебник описывает код из этого же репозитория. Меняете шаблон, настройку или скрипт — поправьте
главу, где он разобран (см. карту выше). Цитаты кода в главах должны совпадать с файлами.
